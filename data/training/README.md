# Training Data

This directory holds VODs used for model development, calibration, parameter
tuning, and persona model training. All data here informs the system's internal
state.

The current stream is a real channel's VOD and is deliberately NOT described here:
its name, its game and its VOD id are the streamer's own, and a repository is not the
place for them. It is a sparse-chat case by design (a few hundred messages across
several hours), which is what stress-tests voice-primary detection.

The local copy is the reference; measure it there.
