SemaClip v26.208 pre-alpha

SemaClip

Opens a Twitch VOD and marks the moments that might be worth clipping, so you can look them over in one pass instead of scrubbing through the whole stream. It runs on your machine, and it keeps working with the network off.

Not finished. Downloading a VOD works, and detection works. Review and export are still being built, so making a clip from start to finish does not work yet. Expect it to break.

Download

Windows

Portable (.zip) Windows · x64 · zip

Nothing to install. Unzip it anywhere you can write, then run SemaClip.exe. Start it through Update and launch SemaClip.cmd and it updates itself.
