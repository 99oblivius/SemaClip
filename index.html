Find the clips in a VOD.

SemaClip watches a Twitch VOD and marks the moments worth clipping — chat spikes, loud reactions, the parts everyone rewound. Everything runs on your machine: no account, no upload, no cloud. Download once and it works offline.

Windows

Installer (.msi) windows · x64 · msi Portable (.zip) windows · x64 · zip

Run the installer. Windows may warn about an unknown publisher — the build is signed by nobody yet.

Linux

AppImage linux · x64 · AppImage

No install: chmod +x the file, then run it. Needs webkit2gtk.

This is pre-alpha. Downloading, detection and review work today; the app is missing features and will break in places. It reports its own problems instead of hiding them — if something looks wrong, it probably is, and it should say so.

Local-first

Detection, transcription and export all run on your hardware. Your VODs never leave the machine.

Streams while it downloads

A scrubbable preview appears within seconds and grows as the file arrives, so you can start reviewing immediately.

Nothing to configure

Point it at a VOD or a folder and it works out the rest — resolution, proxy quality and CPU use have sensible defaults.
